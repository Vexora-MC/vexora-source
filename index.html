Vexora Kodi source

One complete Vexora build for Kodi 21.

The same Wizard and matching skin are used on Windows and UWP/Xbox. Xbox installation, controller and playback verification still require physical-console acceptance.

Add source in Kodi: https://djmlogistics.github.io/vexora-source/

  1. Install from ZIP: repository.vexora.zip
  2. Install from repository → Vexora Repository → Program add-ons → Vexora Wizard.
  3. Open Vexora Wizard and choose the complete build installation.

Wizard includes the original Vexora skin, downloads all six build repositories, makes a backup, and uses Kodi native installation. Optional add-ons install from Movies/Sports/Kids tiles with one OK/Cancel prompt.
